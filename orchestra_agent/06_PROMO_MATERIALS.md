# 2. Open Claude Code in worktree

# 3. Check status

## How It Works

```
Claude Code → Features-Orchestrator → Dependency Check
    ↓
Token-Optimizer → Prompt Rewrite (Save 50-70%)
    ↓
Development in isolated Worktree
    ↓
Git Hooks → Auto-update Status
    ↓
Monitor with Feature-Orchestrator
    ↓
Merge → Auto-detect Unblocked Features
```

## Troubleshooting

**Q: Hooks not running?**
A: Run `bash .orchestra/setup-hooks.sh` to reinstall

**Q: Status not updating?**
A: Manually edit `.orchestra/feature-status.json`

**Q: Want to override pre-push check?**
A: Answer "y" to the confirmation prompt

**Q: Token estimates seem wrong?**
A: They're approximations. Track actual usage in `.orchestra/token-log.json`
